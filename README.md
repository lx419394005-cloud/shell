## 🎯 项目简介

Pics AI 是一款集智能对话与图像生成于一体的 Web 应用，支持多种 AI 模型，提供流畅的创作体验。

## 🛠️ 技术栈

| 分类 | 技术 |
|------|------|
| 框架 | React 19 + TypeScript |
| 构建 | Vite 7 |
| 样式 | Tailwind CSS 4 + Sass |
| 动画 | Framer Motion |
| 图标 | Lucide React |
| 图片处理 | html-to-image |
| HTTP | Axios |
| PWA | Vite PWA Plugin |

## 📦 安装与运行

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 生产构建
npm run build

# 代码检查
npm run lint

# 预览生产版本
npm run preview
```

## 🌟 功能特性

- 🎨 **AI 图像生成** - 支持多种风格与模型
- 💬 **智能对话** - 自然语言交互体验
- 📱 **PWA 支持** - 可安装到桌面/手机
- ⚡ **快速响应** - Vite 极速开发体验
- 🎭 **流畅动画** - Framer Motion 驱动
- 🖼️ **图片导出** - 高质量图像输出

## 📁 项目结构

```
shell/
├── public/              # 静态资源
├── src/
│   ├── assets/         # 项目资源
│   ├── components/     # React 组件

│   ├── utils/          # 工具函数

│   ├── main.tsx        # 入口文件
│   └── index.css       # 全局样式

├── index.html          # HTML 入口
├── package.json        # 项目配置
├── vite.config.ts      # Vite 配置
└── tsconfig.json       # TypeScript 配置
```

## 🔧 开发指南

### 环境要求

- Node.js 18+
- npm 9+ 或 pnpm 8+

### 添加依赖

```bash
# 安装新依赖
npm install <package-name>

# 安装开发依赖
npm install -D <package-name>
```
